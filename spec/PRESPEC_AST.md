# Pre-specification: audit-efficient threshold calibration by two-phase active statistical inference (frozen before any run)
Date: 2026-11-26. Context: CQ, TPC, audit-budget law and tilting failed their pre-registered tests; only trusted labels helped, but uniform audits fail at small budgets (n_a * alpha < 1; FPR 0.1%).
Literature basis: active statistical inference (Zrnic & Candes, arXiv 2403.03208: model-guided sampling + augmented inverse-propensity estimator), prediction-powered inference, Neyman allocation in stratified sampling, isotonic regression. Nearest threshold-under-label-noise work: Yao, Rava, Tong & James (arXiv 2112.00314), Tittelfitz (arXiv 2308.02695).
## Idea
Observed positives are true positives (flips are one-sided). Only observed negatives can be contaminated, and the contamination probability p(s) = P(flipped | observed negative, score s) is monotone increasing in s. The true-negative mass above t is M(t) = sum over observed negatives with s > t of clean_i. Audit a budget of B observed negatives chosen by a two-phase design and estimate M(t) with an augmented inverse-propensity (AIPW) estimator whose proxy is the learned purity 1 - p(s). The threshold is the smallest grid point with M(t)/N0 <= alpha, N0 = estimated number of true negatives.
## Algorithm (exact; implemented in code_sec/mk7.py -> cq7_run.py)
1. Observed negatives U (scores so), observed positives L. Contamination support start u = 2% quantile of L scores if |L| >= 20 else (1 - 5 alpha) quantile of so. Region R = {observed negatives with s > u}. If |R| < 30 or B < 20: fall back to the naive threshold.
2. Phase 1: audit B1 = min(max(10, B // 2), |R|) items drawn uniformly without replacement from R. Fit isotonic (increasing, clipped to [0,1]) regression of the flipped indicator on score -> p_hat(s).
3. Proxy threshold t0: smallest grid point (2001 pool quantiles in [0.5, 1] of so... 1,500 points) with sum_{s_i > t}(1 - p_hat(s_i)) / sum_i (1 - p_hat(s_i)) <= alpha.
4. Phase 2: among observed negatives with s >= t0 draw audit items independently with probability pi2_i = min(1, (B - B1) w_i / sum w), w_i = sqrt(p_hat(1 - p_hat) + 0.02) (Neyman allocation).
5. Total inclusion probability pi_i = 1 - (1 - pi1_i)(1 - pi2_i). AIPW per-item clean estimate: m_i + 1[audited_i] (c_i - m_i)/pi_i, m_i = 1 - p_hat(s_i), c_i = 1[true negative]. N0 = sum_i; M(t) = sum over s_i > t. Threshold = first grid point with M(t)/N0 <= alpha (grid fallback: last grid point).
6. Budget B = max(20, round(f * n_val)) audited items, f in {0.2%, 0.5%, 1%, 2%, 5%} (the same f as the uniform audit rule aud_f, so budgets are equal). Rules: ast_f. Seeds: rule-specific (seed + 277 + 10000 f).
## Declared weaknesses
Phase 2 sampling depends on phase-1 labels (sample-splitting approximation of pi_i); assumes the audit sample is drawn from the same window as the pool (no drift between audit and test windows); isotonic fit noisy at tiny B. Simulation pre-test only (Gaussian scores, 40,000 items, flip 0.4, prevalence 0.05 and 0.2): abs calibration at alpha 0.1%, B = 200: AST 0.56 / 0.88 vs uniform audit 2.32 / 2.41; at alpha 1%, B = 50: 0.33 / 0.66 vs 1.44 / 1.49.
## Design
Noise: random, delay, delay2; poison 0, 0.2, 0.4; FPR 1% and 0.1%; LR/RF/XGB; BASE, CW. Dev: creditcard, IEEE-CIS, UNSW-NB15. Confirmation (analysed after dev): Elliptic, CIC-IDS2017. All older rules (naive, oracle, cq, trust, aud_f, audnp_f, npu, conf, cl, ...) are recomputed in the same runs for paired comparisons.
## Hypotheses (paired over units; Holm within each hypothesis; alpha 0.05; units share windows so p-values are descriptive)
HS1 (efficiency): at equal budget f in {0.2%, 0.5%, 1%}, ast_f has lower absolute calibration than aud_f, Holm-significantly, in a majority of dev dataset x noise x op x poison cells (poison >= 0.2).
HS2 (utility): ast_0.5% lowers absolute calibration vs naive, Holm-significantly, in a majority of dev cells including FPR 0.1% cells.
HS3 (confirmation): HS1 and HS2 hold on at least one of Elliptic and CIC-IDS2017.
HS4 (reporting, not a pass/fail claim): the smallest f at which ast_f is within 1.0 of the oracle's absolute calibration, per dataset and operating point; any cell where ast_f is worse than naive is listed.
Any failure is reported as such; nothing is retuned.
## Novelty note
Active statistical inference and AIPW are published; the contribution would be their application to fixed-FPR threshold calibration with audited labels under one-sided poisoning, the purity-model design, and the quantified budget efficiency and failure boundaries.
